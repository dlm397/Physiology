# Watch7 / Samsung Health datasets

## Description

This project began as a simple data archive, as health data from watches, scales, etc. is not kept forever, particularly in the case of high-resolution data. I have been expanding it to include some statistics analysis, for my own benefit, as well as practing N-of-1 techniques.

## Layout

```text
Data/                          All contents are kept private
  dataGet.py                   Private Python data access
  dataGet.do                   Private Stata data access
Output/                        Products of data analysis
requirements.txt               Python dependencies
README.md                      This dataset catalog and usage guide
```
